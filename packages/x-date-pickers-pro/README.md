# @stackworx/react-hook-form-mui-x-date-pickers-pro

React Hook Form bindings for MUI X 9 Pro range pickers: `DateRangePicker`, `DateTimeRangePicker`
and `SingleInputDateRangeField`. The form value is `[start, end]`, or your own shape via `transform`.

```bash
npm install @stackworx/react-hook-form-mui-x-date-pickers-pro @mui/x-date-pickers-pro @mui/x-date-pickers react-hook-form @mui/material
```

Examples and API: https://github.com/stackworx/react-hook-form-mui#readme

Upgrading from 0.0.x: https://github.com/stackworx/react-hook-form-mui/blob/main/MIGRATION.md
