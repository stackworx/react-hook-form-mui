# @stackworx/react-hook-form-mui-x-date-pickers

React Hook Form bindings for MUI X 9 pickers and fields: `DatePicker`, `TimePicker`,
`DateTimePicker`, `DateField`, `TimeField` and `DateTimeField`. Adapter-agnostic, with MUI's
validation surfaced as form errors.

```bash
npm install @stackworx/react-hook-form-mui-x-date-pickers @mui/x-date-pickers react-hook-form @mui/material
```

Examples and API: https://github.com/stackworx/react-hook-form-mui#readme

Upgrading from 0.0.x: https://github.com/stackworx/react-hook-form-mui/blob/main/MIGRATION.md
