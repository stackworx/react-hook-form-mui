# @stackworx/react-hook-form-mui

React Hook Form bindings for MUI 9: `TextField`, `NumberField`, `Select`, `Checkbox`, `Switch`,
`CheckboxGroup`, `RadioGroup`, `ToggleButtonGroup`, `Autocomplete` and `AsyncAutocomplete`.

```bash
npm install @stackworx/react-hook-form-mui react-hook-form @mui/material @emotion/react @emotion/styled
npm install @base-ui/react # only for NumberField (@stackworx/react-hook-form-mui/number-field)
```

Examples and API: https://github.com/stackworx/react-hook-form-mui#readme
